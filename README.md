# sky+（スカイプラス）

そらのほしが提供する、先生・生徒・保護者をつなぐ教育支援Webアプリのデモです。
QRコードを使った入退室・出欠管理を中心に、授業予定・お知らせ・欠席連絡などの機能を備えています。

このアプリは単一の `index.html` ファイルのみで動作します（ビルド不要・フレームワーク不要）。
データはブラウザの `localStorage` に保存されるデモ用データです（サーバー・データベースは使用していません）。

## GitHub Pages で公開する方法

1. このリポジトリを GitHub に作成し、`index.html` と `.nojekyll` をルート（一番上の階層）に置いてコミット・プッシュします。
2. GitHub のリポジトリ画面で **Settings → Pages** を開きます。
3. **Source** を `Deploy from a branch` にし、Branch を `main`（または使用しているブランチ）、フォルダを `/ (root)` に設定して **Save** します。
4. しばらくすると `https://（ユーザー名）.github.io/（リポジトリ名）/` で公開されます。

## 注意事項

- カメラを使ったQR読み取り機能は、`https://` または `localhost` のようなセキュアな環境でのみ動作します（GitHub Pages は `https://` なので問題なく動作します）。
- データはブラウザ内保存のみのデモです。実運用にはサーバー・データベース・認証基盤の実装が別途必要です。
